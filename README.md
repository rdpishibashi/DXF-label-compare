# DXF Label Compare

`DXF-extract-labels` が出力したExcelのラベル差分を比較し、Excel形式で出力する
Streamlitアプリです。

## 同じExcel内で比較（新機能）

1つの抽出ラベルExcelをアップロードし、Bにする個別図面シートを選ぶだけで、今回の比較を
繰り返し実行できます。

- **A**: `Summary` シートの `タイトル` に `UNIT内結線図` を含む図番の個別シートを全て統合
  します。タイトルの `ＵＮＩＴ` と `UNIT` は同じものとして扱います。
- **B**: 画面で選択した個別図面シートのラベル一覧です。
- **出力**: 比較結果に加え、Aの統合ラベル一覧、Bのラベル一覧、Aの対象図番一覧を含む
  Excelをダウンロードできます。
- **ラベル表記**: ラベルそのものは正規化せず、元の表記のまま重複除外・比較します。

## 2つのExcelを比較（従来機能）

`DXF-extract-labels` が出力した2つのExcelファイル（A: 展開接続図／B: UNIT内結線図）の
`Total` シートに含まれるラベルを比較し、差分（A のみ／B のみ／両方）をExcel形式で出力します。

## 機能

- **ラベル比較**: 2つのExcelファイルの `Total` シートの `ラベル` 列を正規化した上で
  比較し、A のみ・B のみ・両方に分類
- **正規化**: 日本語（ひらがな・カタカナ・漢字）以外のラベルは、全角文字があれば
  半角に変換してから比較（例: `ＣＮ１` と `CN1` は同一ラベルとして扱う）
- **個数の扱い**: `個数` は比較には使わない（同じラベルで個数が異なっても「両方」に
  分類する）が、差分テーブルには参考情報として両方の個数を出力する
- **Bの図番フィルタ**: B（UNIT内結線図）は、`Summary` シートの `タイトル` を使って
  比較対象の図番を絞り込める（「UNIT内結線図のみ」／「UNIT内結線図以外」／「全部」）
- **色分け表示**: 区分（両方／A のみ／B のみ）に応じて画面・Excel双方で行を色分け
- **Excel出力**: サマリーシート＋差分シート（ラベル昇順ソート）

## 使用方法

1. **ファイルのアップロード**: A（展開接続図）・B（UNIT内結線図）それぞれに
   `DXF-extract-labels` が出力した Excel（`.xlsx`）をアップロード
2. **（Bのみ）対象範囲を選択**: 「UNIT内結線図のみ」（既定）／「UNIT内結線図以外」／
   「全部」から選ぶ（下記「Bの図番フィルタ」参照）
3. **「比較」ボタンをクリック**: `Total` シートを読み込み、正規化・絞り込みした上で
   比較を実行
4. **結果の確認**: 画面上に色分けされた差分テーブルとサマリー件数が表示される
5. **「Excelをダウンロード」**: 差分結果をExcelファイル（`label_compare.xlsx`）として保存

### 入力ファイルの前提

アップロードするExcelファイルには **`Total` シート**が必要です（`DXF-extract-labels`
の標準出力に含まれる）。`Total` シートに `ラベル`・`個数` 列が無い場合はエラーになります。
B側はさらに `図番` 列（`Total` シート）と `Summary` シートの `図番`・`タイトル` 列も
必要です（図番フィルタに使うため）。

| 列名 | シート | 内容 |
|------|--------|------|
| `ラベル` | Total | ラベル文字列（比較キー） |
| `個数` | Total | 出現総数（比較には使わないが出力する） |
| `図番` | Total | ラベルが出現した図番（カンマ区切り、B側のフィルタで使用） |
| `図番` | Summary | 図面ごとの図番（B側のフィルタで使用） |
| `タイトル` | Summary | 図面のタイトル（B側のフィルタで「UNIT内結線図」判定に使用） |

`Total` シート内でラベルが重複していた場合（通常は発生しない）、正規化後のラベルで
個数を合算してユニーク化します。「個数」欄が空欄のラベルは入力ファイルに存在しない
前提（`DXF-extract-labels` は必ず個数を記録する）のため、空欄チェックは行いません。

### Bの図番フィルタ

B（UNIT内結線図）に指定するExcelには、UNIT内結線図以外の図面（部品図・チェック
リスト等）が混在している場合があります。`Summary` シートの `タイトル` を使い、
比較対象を図番単位で絞り込めます。

| 選択肢 | 対象 |
|--------|------|
| UNIT内結線図のみ（既定） | タイトルが「UNIT内結線図」（全角・半角どちらも可）と一致する図番 |
| UNIT内結線図以外 | 上記に一致しない図番（タイトル空欄も含む） |
| 全部 | 絞り込みなし（全図番が対象） |

- タイトルの一致判定はラベルと同じ正規化ルール（全角ASCII→半角）を適用するため、
  「ＵＮＩＴ内結線図」と「UNIT内結線図」は同一タイトルとして扱います。
- 絞り込みは `Total` シートの `図番` 列（ラベルが出現した図番のカンマ区切りリスト）で
  行います。ラベルの図番リストが選択した図番集合と1つでも重なれば対象に含めます。
- 個数は絞り込み後も `Total` シートに記録された値（全図番分の合計）をそのまま使います
  （選択した図番だけの個数に再計算はしません）。
- A（展開接続図）には図番フィルタはありません（常に全ラベルが対象）。
- 選択した絞り込み条件は、画面表示とサマリーシートの「B 絞り込み条件」に記録されます。

### 正規化ルール

比較の前に、各ラベルへ以下の正規化を適用します。

- 全角ASCII文字（`Ａ-Ｚ`, `０-９`, `！-～` 等）→ 半角に変換
- 全角スペース → 半角スペースに変換
- ひらがな・カタカナ・漢字などの日本語文字は変換しない（そのまま）

文字単位で判定するため、`ＣＮ１番` のような日英混在ラベルは `CN1番` に変換されます。

### 出力ファイルの構成

Excelファイル（既定ファイル名: `label_compare.xlsx`）:

- **サマリーシート**: A・Bのファイル名、B絞り込み条件、ユニークラベル数、
  A のみ／B のみ／両方の件数
- **差分シート**: `ラベル`・`区分`・`A個数`・`B個数` の4列。`ラベル` で昇順ソート。
  区分に応じて行全体を色分け

| 区分 | 色 |
|------|-----|
| 両方 | 緑 |
| A のみ | 青 |
| B のみ | 茶色 |

無い側の個数（例: A のみのラベルの `B個数`）は空欄になります。

## ファイル構成

3層構造（View / Model）で実装しています。

```
DXF-label-compare/
├── app.py                    # View層: Streamlit UI
├── utils/
│   ├── compare_labels.py     # Model層: 正規化・差分判定・サマリー集計（純関数）
│   ├── excel_input.py        # Model層: Total/Summary シートの読み込み
│   ├── drawing_filter.py     # Model層: Bの図番フィルタ（タイトル判定・絞り込み集計）
│   └── excel_output.py       # Model層: 差分Excelの生成
├── tests/unit/                # 単体テスト（Model層）
├── .streamlit/config.toml     # UIテーマ設定
└── requirements.txt
```

### 既知の制約

- 画面上の差分テーブル（`st.dataframe`）で、個数が無いセルは空欄で表示されます。
  内部的には `Int64`（pandas nullable整数型）を文字列化した表示用コピーを使っており、
  これはStreamlit 1.54のデータグリッドが `pd.NA` を灰色の `"None"` として描画してしまう
  仕様（`Styler.format(na_rep=...)` や `column_config.NumberColumn` でも抑制不可、
  実機検証済み）を避けるためです。Excel出力側は最初から正しく空欄になっています。
- ダウンロードしたExcelファイル自体はこの制約の影響を受けません（`write_blank` で
  直接空欄セルを書き込んでいます）。
